# Island photos

Add one landscape photo per island (about 1200 × 750, 16:10 crops best):

- `desert.jpg`: Sandspit
- `tundra.jpg`: Frostholm
- `woodland.jpg`: Oakhaven
- `rainforest.jpg`: Verdant Isle
- `volcano.jpg`: Ember Isle

A missing photo falls back to the coloured placeholder. To use another file name or format, change `image` in `js/biomes.js`.
